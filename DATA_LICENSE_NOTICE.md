# Dataset and attribution

Source: Ryan Lee's Recipe Box, https://eightportions.com/datasets/Recipes/ and https://github.com/rtlee9/recipe-box .

The official `recipes_raw.zip` archive contains three JSON files and a `LICENSE` file. That license is copied verbatim to `docs/DATASET_LICENSE.txt`. Original recipe records remain attributed by source prefix and source hash key. Original source URLs were hashed by the dataset publisher and are not reconstructed or invented.

The GitHub source repository excludes downloaded raw data and the generated SQLite database. The delivered offline bundle includes a database derived from all three files for immediate local execution. Dataset content remains subject to the supplied dataset license; this notice does not replace it or assert additional rights.
